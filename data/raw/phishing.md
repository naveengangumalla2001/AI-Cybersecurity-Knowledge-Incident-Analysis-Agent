# Phishing Attack

## Definition

Phishing is a social engineering technique in which an attacker attempts to deceive a user into revealing sensitive information, clicking a malicious link, opening a malicious attachment, or performing an unsafe action.

## Common Indicators

- Unexpected emails requesting sensitive information
- Suspicious links
- Unknown or spoofed sender addresses
- Urgent requests for passwords or financial information
- Unexpected attachments
- Messages that create unusual pressure or urgency
- Links whose destination does not match the displayed text

## Potential Impact

A successful phishing attack may lead to:

- Credential theft
- Account compromise
- Malware infection
- Unauthorized access
- Data exposure

## Defensive Measures

- Provide security awareness training
- Use email security controls
- Enable Multi-Factor Authentication
- Verify suspicious requests through another communication channel
- Avoid opening unexpected attachments
- Inspect suspicious links carefully
- Report suspicious emails to the security team

## Investigation

Security analysts should investigate:

- Sender information
- Email headers
- URLs
- Attachments
- User interaction with the message
- Authentication activity following the incident
- Other users who received the same message
